# ClassFlow على GitHub — دليل التركيب

نظام إدارة الدروس الخصوصية يعمل بالكامل على GitHub، بدون Google Sheets وبدون خوادم.

## كيف يعمل النظام

| الملف | لمن | أين |
|---|---|---|
| `teacher.html` | لوحة المعلم | المستودع العام (كود فقط، بدون بيانات) |
| `index.html` | صفحة الحجز للتلاميذ | المستودع العام |
| `availability.json` | الساعات المتاحة فقط (بدون أسماء أو أرقام) | المستودع العام — تكتبه اللوحة تلقائيًا |
| `student.html` | الصفحة الشخصية للتلميذ (كلمات، واجبات، بطاقات تدريب) | المستودع العام |
| `s/….json` | محتوى صفحة كل تلميذ — **مشفّر** | المستودع العام — تكتبه اللوحة تلقائيًا |
| `manifest.webmanifest`, `sw.js`, `icon-*.png`, `apple-touch-icon.png` | تثبيت اللوحة كتطبيق على الهاتف | المستودع العام |
| `data.json` | كل البيانات: التلاميذ، الدروس، الدفعات، الخطط | **المستودع الخاص** — تنشئه اللوحة تلقائيًا |
| `inbox.json` | صندوق الطلبات الجديدة القادمة من صفحة الحجز | **المستودع الخاص** — يكتبه سكربت Google |
| `classflow-intake.gs` | سكربت Google الوسيط | يُنسخ إلى Google Apps Script (الخطوة 6) |

**مسار الحجز:**
```
التلميذ ← صفحة الحجز ← سكربت Google ← inbox.json (المستودع الخاص) ← لوحتك
```
1. تحدد أوقاتك في قسم "זמינות" داخل اللوحة.
2. التلميذ يختار يومًا وساعة ويضغط "שלח בקשה"، فيرى فورًا "הבקשה נשלחה".
3. السكربت يفحص الطلب ويكتبه في `inbox.json`، ويرسل لك إيميلًا.
4. لوحتك تفحص الصندوق كل 30 ثانية، فيظهر الطلب في "בקשות" مع علامة 🌐.
5. تضغط "אשר": يُنشأ الدرس، ويُضاف التلميذ إن كان جديدًا، وتُفتح رسالة التأكيد على واتساب، وتختفي الساعة من صفحة الحجز.

> إذا لم يكن السكربت مثبتًا، أو تعطل، يُعرض على التلميذ تلقائيًا إرسال الطلب عبر واتساب، فلا يعلق أبدًا.

## التركيب (مرة واحدة، حوالي 10 دقائق)

### 1. المستودع العام (الموقع)
1. في GitHub اضغط **New repository**.
2. الاسم: `classflow`، النوع: **Public**، وفعّل **Add a README file**.
3. ارفع الملفات (عبر **Add file → Upload files**): `index.html`، `teacher.html`، `student.html`، `availability.json`، `manifest.webmanifest`، `sw.js`، `icon-192.png`، `icon-512.png`، `icon-maskable.png`، `apple-touch-icon.png`.
4. افتح **Settings → Pages**، ثم في **Source** اختر `Deploy from a branch`، والفرع `main` والمجلد `/ (root)`، واحفظ.
5. بعد دقيقة يصبح الموقع جاهزًا:
   - صفحة الحجز للتلاميذ: `https://USERNAME.github.io/classflow/`
   - لوحة المعلم: `https://USERNAME.github.io/classflow/teacher.html`

### 2. المستودع الخاص (البيانات)
1. **New repository**، الاسم: `classflow-data`، النوع: **Private** ⚠️، وفعّل **Add a README file**.
2. لا ترفع إليه أي شيء، فاللوحة ستنشئ `data.json` بنفسها.

> اللوحة ترفض العمل إذا كان مستودع البيانات عامًا. هذه حماية مقصودة.

### 3. إنشاء التوكن (Fine-grained token)
1. افتح: **صورتك → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. **Token name:** `ClassFlow`.
3. **Expiration:** سنة واحدة (ستستبدله من الإعدادات عند انتهائه).
4. **Repository access:** اختر **Only select repositories**، ثم اختر `classflow` و`classflow-data` فقط.
5. **Permissions → Repository permissions → Contents:** اختر **Read and write**. لا تفعّل أي صلاحية أخرى.
6. اضغط **Generate token** وانسخه فورًا، فلن يظهر مرة أخرى.

### 4. الدخول الأول إلى اللوحة
1. افتح `teacher.html` من رابط GitHub Pages.
2. املأ: اسم المستخدم في GitHub، واسمي المستودعين، والتوكن، ثم **كلمة سر جديدة** (8 أحرف على الأقل).
3. التوكن يُحفظ مشفرًا بكلمة السر داخل هذا الجهاز فقط. على كل جهاز آخر (الهاتف مثلًا) تكرر هذه الخطوة مرة واحدة.
4. في **⚙️ הגדרות** أدخل رقم الواتساب الذي تستقبل عليه الطلبات. بدونه لن تعمل صفحة الحجز.

### 5. نقل البيانات من النظام القديم
في **⚙️ הגדרות → גיבוי וייבוא** طريقتان:
- **من Google Sheets:** الصق رابط Apps Script القديم (المنتهي بـ `/exec`) وكلمة سر الجدول، ثم اضغط "ייבא". هذه الطريقة تنقل التلاميذ والدروس والخطط والباقات والأوقات والقوالب.
- **من المتصفح:** إذا كانت اللوحة القديمة مفتوحة سابقًا على نفس العنوان (`USERNAME.github.io`)، يظهر زر "ייבא" مباشرة.

الاستيراد يضيف ما ينقص فقط ولا يحذف شيئًا. **بعد نجاحه أوقف سكربت Google القديم** (Deploy → Manage deployments → Archive)، لأن بياناته كانت مكشوفة لأي أحد.

### 6. سكربت Google لاستقبال الطلبات تلقائيًا
**أ. توكن خاص بالسكربت** (لا تستعمل توكن اللوحة، حتى يبقى لكل واحد صلاحيات أقل):
1. افتح https://github.com/settings/personal-access-tokens/new
2. الاسم: `ClassFlow Intake`، والمدة: سنة.
3. **Repository access:** اختر **Only select repositories** ← `classflow-data` فقط.
4. **Permissions ← Contents:** اختر **Read and write**.
5. اضغط **Generate token** وانسخه.

**ب. إنشاء السكربت:**
1. افتح https://script.google.com واضغط **New project**، وسمّه `ClassFlow Intake`.
2. احذف كل ما في `Code.gs`، والصق محتوى الملف `classflow-intake.gs` كاملًا، ثم احفظ (Ctrl+S).
3. من القائمة الجانبية افتح ⚙️ **Project Settings**، ثم انزل إلى **Script Properties** واضغط **Add script property**. أضف:

| Property | Value |
|---|---|
| `GH_TOKEN` | التوكن الذي أنشأته في (أ) |
| `GH_OWNER` | اسم المستخدم في GitHub |
| `DATA_REPO` | `classflow-data` |
| `SITE_REPO` | `classflow` |
| `NOTIFY_EMAIL` | بريدك الإلكتروني، لتصلك رسالة مع كل طلب جديد (اختياري) |
| `CAL_KEY` | (اختياري، الخطوة 7) مفتاح الربط مع تقويم Google |

4. ارجع إلى المحرر، واختر الدالة **`testSetup`** من القائمة العلوية، واضغط **Run**. سيطلب Google صلاحيات، فاضغط **Review permissions** ← حسابك ← **Advanced** ← **Go to ClassFlow Intake** ← **Allow**. في السجل (Execution log) يجب أن ترى ✅، وإن أضفت بريدًا ستصلك رسالة تجربة.
5. اضغط **Deploy ← New deployment ← ⚙️ ← Web app**، واضبط:
   - **Execute as:** Me
   - **Who has access:** Anyone
   ثم **Deploy** وانسخ رابط **Web app URL** (ينتهي بـ `/exec`).

**ج. الربط باللوحة:**
في **⚙️ הגדרות ← 📨 קבלת בקשות אוטומטית** الصق الرابط، واضغط **🔍 בדוק** ثم **💾 שמור ופרסם**. خلال دقيقة يتحول زر صفحة الحجز من "واتساب" إلى "📩 שלח בקשה".

> **عند تعديل السكربت لاحقًا:** استعمل Deploy ← Manage deployments ← ✏️ ← Version: New version، حتى يبقى الرابط نفسه.

**ما يحمي السكربت:**
- يستقبل الطلبات فقط، ولا يعيد أي بيانات لأي أحد.
- يرفض أي ساعة غير منشورة في الأوقات المتاحة، ويرفض الطلب إذا كانت الساعة نفسها مطلوبة من تلميذ آخر.
- لا يقبل أكثر من 3 طلبات في الساعة من نفس الرقم، ولا أكثر من 40 طلبًا في الساعة إجمالًا.
- فيه فخ خفي للبرامج الآلية.
- توكنه يصل إلى `classflow-data` فقط، ويُحفظ في Script Properties التي لا يراها أحد غيرك.

### 7. ربط تقويم Google (اختياري)
بعد أن تفعّل هذه الخطوة، يُضاف كل درس توافق عليه أو تضيفه إلى تقويم Google الخاص بك، في نفس الساعة. إذا غيّرت الساعة يتحدّث الموعد في التقويم، وإذا ألغيت الدرس أو حذفته يُحذف من التقويم.

1. في لوحة المعلم افتح **⚙️ הגדרות ← 📅 יומן גוגל**، واضغط **🔑 צור מפתח**، ثم **📋 העתק**.
2. في script.google.com افتح **Project Settings ← Script Properties**، وأضف خاصية جديدة:
   - الاسم: `CAL_KEY`
   - القيمة: المفتاح الذي نسخته.
   - (اختياري) إذا أردت تقويمًا آخر غير التقويم الرئيسي، أضف أيضًا `CAL_ID` وقيمته معرّف ذلك التقويم.
3. الصق الكود الجديد للسكربت، ثم شغّل **`testSetup`** مرة واحدة. سيطلب Google إذنًا جديدًا للوصول إلى التقويم، فوافق عليه. يجب أن يظهر في السجل: `📅 יומן גוגל מחובר`.
4. من **Deploy ← Manage deployments ← ✏️ ← Version: New version ← Deploy** انشر النسخة الجديدة. بهذه الطريقة يبقى الرابط نفسه.
5. ارجع إلى اللوحة، واضغط **🔍 בדוק חיבור ליומן**، ثم فعّل **סנכרון אוטומטי**.
6. إذا كانت عندك دروس قادمة من قبل، اضغط **📅 הוסף ליומן את כל השיעורים העתידיים** لتُضاف كلها إلى التقويم.

> بدون المفتاح الصحيح لا يستطيع أحد غيرك الكتابة في تقويمك. وإذا لم تفعّل المزامنة التلقائية، يبقى بجانب كل درس قادم زر 📅 يفتح Google Calendar وقد امتلأت فيه تفاصيل الدرس، فتضغط "حفظ" فقط.

### 8. الصفحة الشخصية للتلميذ
في صفحة التلميذ داخل اللوحة توجد بطاقة **🎓 הדף האישי**. اضغط **✨ צור דף אישי**، ثم أرسل الرابط للتلميذ عبر واتساب.

- **ماذا يرى التلميذ:** الكلمات والتعابير وقواعد اللغة من الخطط المرتبطة بدروسه، وواجباته وحالتها، وبطاقات تدريب يقلبها ويعلّم عليها "عرفتها" أو "ليس بعد".
- **التحديث تلقائي:** تتحدّث الصفحة بعد كل حفظ في اللوحة.
- **التشفير:** الملف على GitHub مشفّر بـ AES-256، ومفتاح فك التشفير موجود فقط في الرابط بعد علامة `#`. لا يصل هذا المفتاح إلى أي خادم، ومن يتصفح المستودع لا يرى إلا رموزًا غير مفهومة.
- **ما لا يظهر أبدًا:** رقم الهاتف، الدفعات، والملاحظات الخاصة.
- **إذا انتشر الرابط:** اضغط **🔄 קישור חדש**، فيتوقف الرابط القديم عن العمل. وزر **⏸ כבה** يحذف الصفحة كليًا.

### 9. تثبيت اللوحة كتطبيق
افتح `teacher.html` على الهاتف:
- **أندرويد (Chrome):** من القائمة ⋮ اختر "התקנת אפליקציה" أو "הוספה למסך הבית".
- **آيفون (Safari):** من زر المشاركة اختر "הוסף למסך הבית".

يظهر عندها أيقونة ClassFlow على الشاشة الرئيسية، وتفتح اللوحة بدون شريط المتصفح. التعليمات موجودة أيضًا في ⚙️ הגדרות ← 📱.

## الأمان: ما الذي تغيّر

| قبل | الآن |
|---|---|
| كلمة سر الجدول مكتوبة داخل صفحة التلميذ، وأي أحد يستطيع قراءة كل البيانات | لا توجد أي أسرار في الكود. البيانات في مستودع خاص لا يُقرأ إلا بالتوكن |
| رمز دخول من 4 أرقام يُفحص في المتصفح فقط ويمكن تجاوزه | كلمة سر تفك تشفير التوكن (PBKDF2 + AES-256). بدونها لا يمكن الوصول للبيانات |
| ميزة "دروسي" تكشف دروس أي رقم هاتف | صفحة التلميذ لا ترى إلا الساعات الفارغة |
| حفظ متكرر قد يكتب فوق تغييرات جهاز آخر | كشف تعارض بين الأجهزة، وكل تغيير هو Commit يمكن الرجوع إليه |
| السكربت القديم يقرأ ويكتب كل الجداول لمن يعرف كلمة السر | السكربت الجديد يكتب الطلبات فقط، ولا يعيد أي بيانات |
| — | قفل تلقائي بعد عدم النشاط، وسياسة CSP تمنع إرسال البيانات لأي موقع غير GitHub |

**نصائح مهمة:**
- إذا فقدت جهازًا، ألغِ التوكن من GitHub فورًا (Settings → Developer settings → Tokens → Delete)، ثم أنشئ توكنًا جديدًا.
- لا تشارك التوكن ولا تضعه في أي ملف.
- إذا نسيت كلمة السر، اضغط "שכחתי סיסמה / חיבור מחדש" وأدخل التوكن من جديد. بياناتك لا تضيع لأنها في GitHub.
- لاسترجاع نسخة قديمة: افتح `classflow-data` ← `data.json` ← **History**، أو استخدم "שחזור מקובץ" مع نسخة احتياطية.

## ملاحظات
- تحديث صفحة الحجز بعد أي تغيير يستغرق حوالي دقيقة (وقت نشر GitHub Pages).
- الحد الأقصى لحجم `data.json` هو 1MB، وهذا يكفي لآلاف الدروس.
- `teacher.html` موجود في المستودع العام، لكنه كود فقط. من يفتحه بدون توكن وكلمة سر لا يرى شيئًا.
